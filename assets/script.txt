People used to think an agent should represent a human, or a role. We think the relationship is the fundamental unit. So we are proposing the relational agent — born only when people — at least two — see each other and agree, holding only what that relationship shared. One relationship, one agent, one memory.

Let me explain why this change of perspective matters for memory management. Chanho ate egg tarts in Lisbon with Hannah. Tonight Ava asks his agent an innocent question: do Chanho like egg tarts? And it answers  that he likes it because he had it with Hannah.

One agent per relationship closes that door. The Chanho-and-Hannah agent holds the egg tarts. The Chanho-and-Ava agent holds nothing beyond what Chanho and Ava shared. Let's see it live.

Let's take a look at Chanho's relational memory. He signs in with his wallet. He has two exclusive workspaces — one for Hannah, one for Ava. In each private workspace, he can create a relational agent for that relationship.

We made this demo for fun — but the idea is serious. We didn't want to build an agent that replaces humans.
