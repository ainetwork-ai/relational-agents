The relationship is the agent's unit

You see me, therefore I am — an agent that lives in relationships, not in people

  • The hole in the old approach — one agent per person, one shared memory. An innocent question like "do you like egg tarts?" leaks memory from another relationship
  • Turn the question into an injection and that person's entire life leaks out through the same door
  • One relationship = one agent = one memory — born only when both people verify and consent to each other
  • Isolation isn't a rule the model has to follow — it's the structure itself
